# Mini App и рекламные кампании — 31.10.2026

Ветка feat/dealer-tools-promos получает небольшой Mini App: «Сводка»,
«Пользователи», «Кампании». Вход по подписанным Telegram initData; админ видит
всё и выбранного дилера, дилер — свои продажи/кампании и связанных клиентов.
У обычного клиента доступа нет. RU/EN/FA, RTL, без счётчика сырых кликов.
Периоды: сегодня/вчера, 7/30 дней, текущий/прошлый месяц, всё время (МСК).
Рекламная ссылка /start ad_<code> считает уникальных запустивших бота,
закрепляет первый источник и связывает его только с последующими покупками.
Сводка включает подтверждённые покупки/продления и докупки, в том числе
управляемые дилером подписки. Валюты раздельно; USD — списания дилера,
банковская розница в туманах сохраняется отдельным снимком, Stars/USDT —
исходные суммы. Пополнения баланса не считаются повторными продажами.
Новые даты оплат точные; исторические из заказов/логов импортируются
идемпотентно, приблизительные даты отмечены в интерфейсе. Пересчёта старой
розницы по новому курсу нет. Аналитика сохраняется при удалении оперативного
пользователя; источники событий и управляемые подписки защищены от повторного
использования ID в SQLite. Визит и новая оплата используют общий lock клиента
для PostgreSQL; исторический импорт не держит такие locks на живых клиентах.
Добавлены 5 таблиц, существующие таблицы не ALTER-ятся. Старые суммы, статусы,
балансы и VPN-выдача не переписываются. Сервер app.webapp:app, unit
deploy/miran-analytics.service, только 127.0.0.1:8091 за HTTPS-прокси.
ANALYTICS_WEBAPP_URL включает кнопку «Аналитика» в админском/дилерском меню;
пока URL пустой, кнопка скрыта. HTTPS-домен и установку на VPS ещё надо выбрать
и выполнить с пользователем. Детали: docs/2026-10-31-analytics.md.

за успешную оплату. Все новые callback доступны только ADMIN_IDS и проверяют,
что заказ относится к открытому пользователю. История не меняет заказы,
балансы и VPN. Миграция БД не нужна; новая оплата для просмотра архива не нужна.

Выбор: срок 30 / 60 / 90 дней → 1 / 2 / 3 устройства → оплата.
База за первый месяц: $1 / $1.50 / $1.70 для 1 / 2 / 3 устройств.
22.10.2026 пользователь подтвердил коэффициенты со скрина: 1 / 1.5 / 1.7.
Второе устройство: +50% первого; третье: ещё +20% первого.
Сроки имеют множители 1 / 1.90 / 2.70 (скидки 5% и 10% на весь срок).
Суммы за 1 / 2 / 3 месяца: 1 устройство — $1 / $1.90 / $2.70;
2 устройства — $1.50 / $2.85 / $4.05; 3 устройства — $1.70 / $3.23 / $4.59.
Согласованный курс TOMAN_PER_USD=150000: розница за сроки
на 1 устройство — 150000 / 285000 / 405000 туманов;
на 2 — 225000 / 427500 / 607500; на 3 — 255000 / 484500 / 688500.
405000 за 3 месяца взяты из последнего прайса пользователя, заменив прежние
2.71 USD. Серверный .env должен получить курс 150000, а не только default.
Округляется общий итог до центов (ROUND_HALF_UP). Отдельные месячные покупки
оплачиваются по базе. Разовая докупка +50 ГБ стоит $0.50 и не продлевает срок.
Докупка текущего периода не переносится на следующий период.
Дилерская скидка сохранена: при DEALER_DISCOUNT=0.5 списывается половина розницы.
Главная кнопка: «Купить VPN» (старый callback `menu:my_vpn` совместим).
Клиентская и дилерская докупка защищены от повторной обработки одного заказа.
Цены новых продуктов заданы в USD. Старые GB-пакеты только в RETIRED_PLANS:
их старые счета исполняются; новые продажи по старым кнопкам запрещены.
Для fa цены в меню, выборе устройств, подтверждении и докупке показываются
в туманах по TOMAN_PER_USD, персидскими цифрами. Дилерские цены и эквивалент
баланса также в туманах; Order.amount и баланс в БД остаются в своих валютах
(дилер USD, крипто USDT, Stars XTR). Перевод суммы в туманы округляется
до целого ROUND_HALF_UP. Цены в подсказках подставляются из каталога,
жёстко заданных долларовых цен в fa нет. При смене курса меню открыть заново.
При создании банковского заказа FSM сохраняет retail_toman из реквизитов.
В уведомлении о чеке этот снимок не пересчитывается по новому курсу.
Если у старого месячного заказа снимка нет, показывается указание проверить
первоначальные реквизиты. Сохранённая USD-сумма заказа не меняется.
Число устройств хранится в SKU заказа: month1/2/3 для одного,
monthNd2 / monthNd3 для двух/трёх. Дополнительная миграция БД не нужна.
Выбранный hwidDeviceLimit передаётся при покупке/продлении, применяется сразу;
докупка и фоновый сброс трафика его не меняют. Нужен включённый HWID Device Limit
на панели/External Squad и приложение с HWID; глобальные настройки бот не меняет.
Подробности: `docs/2026-10-21-monthly-plan.md`, `docs/2026-10-21-device-options.md`.
