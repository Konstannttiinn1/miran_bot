## Что это за проект

**IR2_VPN** — Telegram-бот для автоматизации продажи VPN-подписок.

Он закрывает основной путь клиента прямо внутри Telegram:

**выбор языка → выбор тарифа → оплата → выдача VPN → управление подпиской → продление**

Бот можно использовать как основу собственного VPN-магазина и адаптировать под любой бренд, тарифную сетку, язык, валюту и инфраструктуру.

Это не просто меню с кнопкой «Купить». Бот связан с **3x-UI**, создаёт и продлевает клиентов в панели, выдаёт subscription link и хранит состояние пользователей, заказов и подписок в базе данных.

## Single-screen UX

Обычная навигация не спамит чат новыми сообщениями.

После первого экрана бот в основном **редактирует одно сообщение с логотипом**:

```text
Главное меню
    ↓
Мой VPN
    ↓
Тарифы
    ↓
Способ оплаты
    ↓
Назад
```

Меняются caption и inline-кнопки, а сам экран остаётся на месте.

Новые сообщения появляются только там, где это действительно нужно: Telegram invoice, чек клиента, подтверждение оплаты и системные события.

## Telegram Stars

Stars реализованы как полноценный платёжный flow:

```text
Клиент выбирает тариф
        ↓
Создаётся Order
        ↓
Telegram invoice (XTR)
        ↓
pre_checkout_query
        ↓
Проверка user / order / amount / currency
        ↓
successful_payment
        ↓
Сохраняется telegram_payment_charge_id
        ↓
VPN выдаётся через 3x-UI
        ↓
Order → paid
```

VPN **не выдаётся по нажатию кнопки** — только после подтверждённого `successful_payment`.

## Дилерская модель

В проект встроен отдельный сценарий продаж через дилера.

Клиент может оплатить заказ дилеру и отправить в бота подтверждение платежа. Дилер получает заказ с кнопками подтверждения и отклонения.

```text
Клиент
  ↓
Выбирает оплату через дилера
  ↓
Получает реквизиты
  ↓
Отправляет чек
  ↓
Дилер получает заказ
  ↓
             ┌──── ✅ Confirm
             │       ↓
             │   проверка баланса
             │       ↓
             │   списание USD
             │       ↓
             │   выдача VPN
             │
             └──── ❌ Reject
                     ↓
                 заказ закрывается
```

### Внутренний баланс дилера

Внутренний баланс дилера ведётся в **USD**.

Администратор заранее пополняет баланс дилера, а при подтверждении нового заказа с него автоматически списывается дилерская стоимость.

Например:

```text
Розничная цена тарифа:      $10
Дилерская скидка:           50%
Списание с баланса дилера:   $5

Баланс до заказа:           $100
Баланс после заказа:         $95
```

Размер дилерской скидки задаётся настройкой `DEALER_DISCOUNT`.

Если 3x-UI не смог выдать VPN после подтверждения заказа, списанная сумма **автоматически возвращается дилеру**.

Обработка защищена от повторного подтверждения: первый дилер, который забрал заказ в работу, блокирует его для остальных.

## Интеграция с 3x-UI

Бот работает с **3x-UI API** и использует Telegram ID клиента как стабильный идентификатор.

Основной сценарий:

```text
Telegram user
      ↓
Order paid
      ↓
Subscription service
      ↓
3x-UI API
      ↓
create / update client
      ↓
subId
      ↓
subscription URL
      ↓
Telegram user
```

При повторной покупке существующего клиента оставшиеся дни сохраняются, а новый срок добавляется сверху.

## Быстрый старт

### 1. Клонировать репозиторий

```bash
git clone https://github.com/Konstannttiinn1/miran_bot.git
cd miran_bot
```

### 2. Создать virtual environment

```bash
python -m venv .venv
source .venv/bin/activate
```

Windows:

```powershell
.venv\Scripts\activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Создать `.env`

Пример базовой конфигурации:

```env
BOT_TOKEN=your_telegram_bot_token
ADMIN_IDS=123456789

DB_URL=postgresql+asyncpg://user:password@localhost/database

XUI_HOST=https://your-panel.example.com
XUI_BASE_PATH=
XUI_TOKEN=your_xui_api_token
XUI_INBOUND_ID=1
XUI_SUB_URL=https://your-subscription-domain.example.com/sub

SUPPORT_USERNAME=@your_support

AVAILABLE_LANGS=fa,en,ru
USE_CUSTOM_EMOJI=false

RUB_PER_USD=90
DEALER_DISCOUNT=0.5
STARS_REWARD_USD=0.013

DEALER_CARD_NUMBER=your_payment_details
DEALER_CONTACT=@your_dealer

HELEKET_ENABLED=false
HELEKET_MERCHANT_ID=
HELEKET_API_KEY=
HELEKET_WEBHOOK_URL=
```

> Никогда не коммитьте реальный `.env`, токены, пароли, API keys и платёжные секреты в GitHub.

### 5. Запустить

```bash
python main.py
```

## Тарифы и цены

Тарифы находятся в:

```text
app/utils/tariffs.py
```

В одном месте задаются:

- срок подписки;
- лимит трафика;
- базовая цена;
- параметры отображения тарифа.

Интерфейс может показывать разные валюты для разных локалей, а внутренняя дилерская экономика при этом остаётся в USD.

## Custom Emoji

Проект поддерживает custom emoji Telegram:

- в обычных сообщениях — через `<tg-emoji>`;
- в inline-кнопках — через `icon_custom_emoji_id`.

Логика текста и кнопок разделена специально, чтобы обычный emoji и custom emoji не отображались одновременно.

Карта ID находится в:

```text
app/utils/emojis.py
```

- платёжные сценарии;
